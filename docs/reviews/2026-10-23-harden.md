# Hardening pass, Oct 23 (night shift 3)

Goal (tonight.md): harden the features a user or recruiter touches, in this order: the no-login demo, Photos, Share, Groups, Messages, sign-in and invite. Each gap got a failing test (title starts with its HARD ID), then a fix.

## Baseline (main fc67fca)
Jest 619 + 1 skipped (3 runs), typecheck clean, web e2e 4, demo e2e 8, showcase sweep 44 screens at 390 and 1280 wide, light and dark, no console errors. The sweep found no visual breaks, so tonight's work is edge cases.

## Found and fixed

| ID | Feature | P | What went wrong | Fix | Test |
|---|---|---|---|---|---|
| HARD-7 | Demo | P1 | A browser that blocks storage (private window, strict cookie settings, some embeds) throws on `localStorage`; the demo showed a blank page | `platform/webStorage.ts`: a safe accessor and a key/value store that falls back to memory; used by the web session store, settings store, demo seed and Start over | `demo.spec.js` HARD-7, `webStorage.test.ts` |
| HARD-1 | Groups | P1 | If the signal dropped after the group was made but before everyone was added, tapping "Make the group" again tried to make it a second time (the server refuses the duplicate name), leaving a half-filled group | The form remembers the group it made; a retry only finishes adding people (the server's add is already safe to repeat) | `groupsV2.test.tsx` HARD-1 |
| HARD-3 | Share | P1 | With no group to send to, Share showed "Pick who should see it." with nothing to pick | Says "There is no group to send to yet." and what to do (make one, or ask the person who invited you) | `share.test.tsx` HARD-3 |
| HARD-2 | Share | P2 | Picking more than 10 photos silently kept the first 10 | Says how many were left out, and points parents at "Pick lots of photos" | `share.test.tsx` HARD-2 |
| HARD-4 | Invite | P2 | Pasting the whole invite link into "Invite code" said the code was wrong (it upper-cased the case-sensitive link token) | A pasted link opens its own invite | `signin.test.tsx` HARD-4 |
| HARD-5 | Sign-in | P2 | "Use a different email", then the same address again, skipped the one-minute wait and hit the mailer's limit ("Too many tries. Wait 10 minutes.") | The wait holds for the address the code went to, with the seconds shown | `signin.test.tsx` HARD-5 |

## Checked and fine
- HARD-6 Messages (suspected race, not a bug): sends and refreshes share one lock per chat, so a refresh can't hide a message just sent; Send is busy while sending.
- Rename: the server trims names and refuses duplicates; the app shows the plain message.
- Invite code: any case, spaces and dashes (BETA-JOIN-8), and a too-short code goes nowhere.
