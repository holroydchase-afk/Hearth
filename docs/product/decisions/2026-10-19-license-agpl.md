# Decision: Hearth's code is licensed AGPL-3.0, and dual licensing stays possible
Date: Oct 19, 2026 · Status: Chase's (picked AGPL-3.0 on the decision card, Oct 19) · Source: Chase, Oct 19: "I think I would like the open source better, but have maybe clear ways to monitize. if thats the case and agpl-3.0 is the best route, then let me know". Tracker: D10, "Developer edition"

Options weighed: AGPL-3.0, MIT, personal/family only (PolyForm Noncommercial, not OSI open source), AGPL plus a paid commercial license (dual). Dual stays available later as long as Chase owns all the code: a contributor agreement starts with the first outside PR.

Money stays with the hosted plan (storage tiers), the family vault tier and, later, paid setup or support for self-hosters.
