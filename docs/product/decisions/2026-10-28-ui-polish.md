# Decision: one solid button per screen, and a shorter demo bar (UI-1..5)
Date: Oct 28, 2026 · Status: release M1.1 phase 3 (Chase: "UI to 8/10"), built in a draft PR, under "Decisions to review" · Touches DEMO-3, DEMO-6, DEMO-8, MSG-1, DS-3

**What changes.** In Messages, each chat's Open button is a gray button with blue words instead of solid blue, so the screen no longer shows a stack of equal loud buttons (the words, size and 48 pt target are unchanged). The public demo's bar is one line ("Made-up family. You're Sam, a parent.") over one row of chips: As Grandma, Start over, Portfolio; the spoken labels are unchanged. On a laptop the phone sits centred with a shadow beside three proof points and a "Read the case study" link. The demo's Me screen says "You're Sam, in the made-up sample family." instead of a placeholder email. The real app's Me screen is unchanged.
